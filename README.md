# Intro

[Play on Armor Games](https://armorgames.com/space-cowboy-game/19211p)

**Made With: Unity, C#**
\
**Contributions: Solo Developer (except sourced free music and SFX)**

Space Cowboy is my first try at a full polished web game with the aim of being hosted on sites for web games that I used to love playing on as a kid. I gave myself a 1 month timeline to keep the scope small. The main mechanics are using the kickback of your revolver with a limited number of bullets and your lasso to redirect your momentum around asteroids. The player must find a way to use their resources in each level to avoid cacti and collect all the solar cows. The game includes 20 levels of varying difficulty and fun gimmicks.

After release I got a lot of feedback from players, with the main complaint being the difficulty curve. From this I learned I should have playtested a lot more with others, as I got too used to the mechanics and couldn't judge accurately what a new player would experience in the first several levels.
